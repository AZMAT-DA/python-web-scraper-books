# Python Web Scraper - Books to Scrape

## About
A Python web scraping project using Requests and
BeautifulSoup to collect book information.

## Features
- Scrapes 50 pages
- Collects book titles, prices and availability
- Saves results in CSV format
- Checks total row count
- Detects missing prices and titles
- Generates a data quality report

## Technologies
- Python
- Requests
- BeautifulSoup
- CSV

## How to Run

Install libraries:

pip install requests beautifulsoup4

Run the scraper:

python scraper.py

## Output
The scraper generates all_books_checked.csv.
